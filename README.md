# 📊 Telecom Churn Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze customer churn in the telecom industry. The dashboard helps identify churn patterns, customer behavior, and key business insights that can support retention strategies.

---

## Objectives

- Analyze customer churn trends
- Identify factors contributing to customer attrition
- Track customer demographics and service usage
- Provide actionable insights for business decision-making

---

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Excel / CSV Dataset

---

## Dashboard Features

### Executive Summary
- Total Customers
- Active Customers
- Churned Customers
- Churn Rate %

### Customer Analysis
- Churn by Gender
- Churn by Contract Type
- Churn by Payment Method
- Churn by Internet Service

### Revenue Insights
- Monthly Charges Analysis
- Revenue Distribution
- High-Risk Customer Segments

### Interactive Filters
- Gender
- Contract Type
- Internet Service
- Payment Method

---

## Key Insights

- Month-to-month contract customers show the highest churn rate.
- Electronic check payment users are more likely to churn.
- Customers with shorter tenure have higher churn probability.
- Fiber optic users contribute significantly to churn numbers.
